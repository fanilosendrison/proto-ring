`proto-ring` is the canonical shared governance substrate being derived from concrete governance needs demonstrated by `Turnlock` and `Ruu`. It compares their strengths, constraints, and failure modes, derives the strongest justified consumer-independent contracts, and provides reusable mechanisms that each repository binds without transferring local authority.

It does not treat either consumer as the reference implementation, reduce sharing to the lowest common denominator, invent governance unsupported by demonstrated need, or attempt to specify the complete future `Ring` product.
